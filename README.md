# Banc-de-test-HIL-passerelles-industrielles
Conception et réalisation d’un banc de test HIL pour la validation des interfaces de communication et des signaux industriels. Étude des besoins, conception des circuits électroniques et des PCB, intégration d’un ESP32, génération de signaux analogiques (0–10 V, 4–20 mA), communication RS-485/Modbus et CAN, avec supervision Python.
